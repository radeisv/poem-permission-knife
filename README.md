The Knife, Handle First — a short poem about agency: the power to ask and to be given. A program that writes one poem to `/output/entry.txt`: a child asking to hold the knife — not the bread, the cutting of it. Permission is trust with the sharp edge, handed over handle first, and the loaf tastes of yes.

## Run it

```sh
python3 main.py
```

It writes the poem to `/output/entry.txt`. No network, no randomness, no model call — every run writes the same bytes.
